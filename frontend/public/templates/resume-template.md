# 简历模板（通用版）

> 本模板面向 Job Insight Platform 的简历解析与推荐系统，目的是让你上传的简历能被系统正确识别目标岗位、城市、学历、经验、技能、项目、奖项与证书，从而给出更贴合的职位匹配和薪资参考。

## 基本信息

- 姓名：
- 手机：
- 邮箱：
- 目标岗位：如 Java 后端工程师 / Backend Engineer
- 当前岗位：如 Java 工程师
- 目标城市：如 北京 / 上海 / 深圳
- 目标行业：如 互联网 / 金融科技 / 人工智能
- 学历：本科 / 硕士 / 博士
- 工作年限：如 3 年

## 技能

> 技能请优先使用逗号 "," 、中文逗号 "，"、顿号 "、"、斜杠 "/"、分号 ";" 分隔，不建议只用空格分隔，否则可能被识别为一个长串。

示例：

```
Java, Spring Boot, MySQL, Redis, Docker, Kafka, MyBatis, Git, Linux
```

## 项目经历

> 每个项目建议写成「背景 → 动作 → 结果」三段式，并尽量量化。
> 动作写"具体做了什么"，结果写"带来了什么变化"。

**项目名称**（起止时间）

- 背景：简述业务场景、团队规模、技术栈。
- 动作：负责模块、关键技术决策、解决的核心问题。
- 结果：可量化指标，如"接口 P99 从 800ms 降至 180ms"、"活动报名率提升 28%"。

## 工作经历

**公司名称 · 岗位**（起止时间）

- 在岗期间的主要职责与代表性产出。
- 使用的技术栈、负责的模块规模、跨团队协作情况。

## 教育经历

- 学校 · 专业 · 学历（起止时间）
- 相关课程、GPA、科研或实验室经历（可选）

## 奖项与证书

> 建议写清奖项名称、级别（国家级 / 省级 / 校级）与获得时间。
> 当前系统会识别奖项名称、级别并给出基础含金量评分。

- 2024 · 全国大学生数学建模竞赛 · 国家一等奖
- 2023 · 软件设计师（中级）
- 2022 · 校级优秀学生干部

## 自我评价（可选）

- 最擅长的技术方向与业务场景。
- 近期希望补齐的能力。
- 求职偏好：城市、行业、公司规模、融资阶段。

---

> 写完后请保存为 PDF / DOCX / TXT / MD 上传到"智能推荐 · 简历优化"页面，
> 系统会自动识别基本信息、技能、经历、奖项，并同步到"职位匹配"与"薪资参考"。
