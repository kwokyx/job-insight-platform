# 分布式数据采集模块交付说明

## 1. 交付范围

当前交付的是分布式数据采集模块第一阶段联调版本，已完成以下能力：

- 调度中心创建任务、拆分任务、分发分片
- 爬虫节点消费分片并执行智联招聘采集
- RabbitMQ 传递任务消息、数据消息、结果消息、心跳消息
- MySQL 持久化任务、分片、节点、日志与职位明细
- HDFS 按固定目录结构保存职位原始明细 JSONL 文件

当前版本可以与 Spring Boot 进入整合联调阶段，但还不包含 Hive 外表、Spark 分析作业、趋势统计结果表和推荐特征加工。

## 2. 数据存储位置

### 2.1 MySQL

MySQL 当前仍保存系统运行所需的事务型数据：

- `crawl_task`
- `crawl_task_shard`
- `crawl_worker`
- `crawl_task_log`
- `system_config`
- `job_data`

其中 `job_data` 目前作为过渡兜底仍保留写入，便于调试和对账。

### 2.2 HDFS

职位原始明细同时写入 HDFS，当前固定根目录为：

```text
/data/recruitment_crawler
```

原始明细目录为：

```text
/data/recruitment_crawler/ods/job_detail/channel=zhaopin/dt=<YYYY-MM-DD>/
```

例如：

```text
/data/recruitment_crawler/ods/job_detail/channel=zhaopin/dt=2026-04-19/
```

目录中的多个 `part-*.jsonl` 文件共同组成同一天的完整数据集。

### 2.3 HDFS 字段范围

进入 HDFS 的字段固定为以下 21 个：

- `url`
- `url_obj_id`
- `title`
- `salary_min`
- `salary_max`
- `salary_raw`
- `job_city`
- `experience_year`
- `education_need`
- `publish_date`
- `job_welfare`
- `job_labels`
- `position_info`
- `job_classification`
- `company_name`
- `company_size`
- `company_finance`
- `crawl_time`
- `crawl_update_time`
- `company_logo`
- `task_id`

时间字段统一格式为 `%Y-%m-%d %H:%M:%S`。

## 3. 对后端的接口说明

当前后端整合主要对接调度中心 FastAPI 接口，重点接口如下：

### 3.1 任务接口

- `POST /api/tasks/`
  - 创建采集任务
- `POST /api/tasks/{task_id}/start`
  - 启动任务
- `POST /api/tasks/{task_id}/pause`
  - 暂停任务
- `GET /api/tasks/`
  - 查询任务列表
- `GET /api/tasks/{task_id}`
  - 查询任务详情
- `GET /api/tasks/{task_id}/shards`
  - 查询任务分片
- `GET /api/tasks/{task_id}/stats`
  - 查询任务统计

### 3.2 节点与监控接口

- `GET /api/workers`
  - 查询节点列表
- `GET /api/monitor/dashboard`
  - 仪表盘统计
- `GET /api/monitor/task-stats`
  - 任务统计
- `GET /api/monitor/data-stats`
  - 数据统计
- `GET /api/logs`
  - 日志查询

### 3.3 推荐整合方式

当前建议 Spring Boot 先整合两类内容：

- 调度中心已有任务与监控接口
- HDFS 原始数据位置说明和后续分析层约定

当前不建议 Spring Boot 直接扫描 HDFS JSONL 原始文件做在线分析，后续推荐接入方式是：

- 先由 Hive/Spark 对 HDFS 原始明细做分析
- 再把分析结果回写 MySQL 结果表或提供分析接口
- Spring Boot 读取结果表或调用分析接口

## 4. 项目启动方式

### 4.1 基础依赖

启动前需要先准备并运行：

- MySQL
- RabbitMQ
- Redis
- Hadoop/HDFS 集群

### 4.2 HDFS 要求

当前 HDFS 集群角色约定：

- `hadoop001`：NameNode
- `hadoop002`：DataNode
- `hadoop003`：DataNode

需要保证：

- `dfs.webhdfs.enabled=true`
- NameNode WebHDFS 可访问 `9870`
- 目录 `/data/recruitment_crawler/ods/job_detail` 已创建

### 4.3 调度中心启动

```powershell
cd F:\Spring26\HuaDi\DistributedDataAcquisition_V3\scheduler-center
..\venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8001
```

启动成功后应看到日志：

- `HDFS 批量写入线程已启动`
- `所有消息队列消费者已启动`

### 4.4 爬虫节点启动

```powershell
cd F:\Spring26\HuaDi\DistributedDataAcquisition_V3\crawler-node
..\venv\Scripts\python.exe .\main.py
```

### 4.5 测试创建最小任务

```powershell
curl -X POST "http://127.0.0.1:8001/api/tasks/" ^
  -H "Content-Type: application/json" ^
  -d "{\"task_name\":\"hdfs_min_test\",\"channel\":\"zhaopin\",\"keywords\":[\"Python\"],\"city\":[\"成都\"],\"page_count\":1,\"priority\":5,\"schedule_type\":\"IMMEDIATE\",\"schedule_mode\":\"IMMEDIATE\",\"schedule_enabled\":false,\"schedule_timezone\":\"Asia/Shanghai\",\"incremental\":false,\"incremental_page_limit\":1,\"stale_page_threshold\":1,\"lookback_hours\":24,\"create_user\":\"manual_test\"}"
```
