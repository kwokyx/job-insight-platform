模块功能
对系统管理员、教师、学生等各类用户进行身份核验。通过比对数据库凭证发放JWT访问令牌，并根据角色返回对应的动态路由配置，实现前端页面的权限分发。

性能要求
登录响应需在2秒以内，支持高并发认证请求。
限制条件
1. 终端需具备稳定的网络连接；
2. 客户端需支持 Web Storage 以存储 JWT 令牌。
输  入
username (用户名), password (明文密码), 类型均为 String。
输  出
token (JWT 字符串), role (用户角色), menus (权限路由列表), msg (提示信息)。
算法逻辑
1. 请求拦截：前端 POST 请求至/api/auth/login，拦截器执行参数非空校验。
2. 账户检索：调用UserMapper查询sys_user表，核验账号存在性及 status 激活状态。
3. 凭证比对：利用BCryptPasswordEncoder执行密码哈希比对，保障凭证安全 。
4. 令牌生成：核验通过后，通过 Jwts 生成包含userId与role的JWT令牌。
5. 缓存处理：将 Token 及权限摘要写入 Redis 缓存，优化高频鉴权性能。
6. 结果下发：封装认证结果，返回Token及重定向路径。
相关对象及接口
1. 上层调用：前端 Login.vue 组件通过 Axios 异步调用。
2. 核心服务：AuthService（业务逻辑）、JwtTokenUtil（令牌加解密）。
3. 下层支撑：UserMapper（MySQL持久化）、RedisTemplate（热点数据读写）。
4. 数据结构：UserLoginDTO（输入）、AuthResponseVO（输出）、sys_user（实体类）。

输  出
原始岗位JSON数据流、采集执行日志。

1. 任务分发：主节点读取任务并按页码/城市切分为子任务写入消息队列。
2. 分布式抓取：从节点监听队列，获取任务后切换代理IP执行抓取。
3. 异常处理：若采集失败，触发重试机制或重分配任务。
相关对象及接口
1. 上层调用：平台管理后台发起手动触发或Cron自动触发。
2. 核心服务：CrawlerMasterService（任务拆分）、CrawlerSlaveService（执行抓取）。
3. 下层支撑：RabbitMQ (消息分发)、Redis (去重指纹库)。

算法与模型设计
本平台通过独立部署的FastAPI算法服务提供核心计算支撑，旨在将海量岗位数据转化为深度的就业情报。算法设计侧重于大规模数据的回归分析、复杂关系建模以及高维向量空间的相似度计算，从而为用户提供科学的决策依据。
3.4.1  薪资预测模型设计
薪资预测模型是实现数据洞察的重要工具。该模型主要通过对采集到的海量岗位数据进行特征提取，建立起多维变量与薪资水平之间的关联关系。在模型训练过程中，系统从存储于HDFS的历史底座数据中抽取关键特征，包括城市等级（如北上广深与二三线城市的地域权重）、学历门槛（大专至博士的阶梯分值）、工作经验年限以及具体的技能标签向量。
在算法选型上，系统采用了XGBoost回归算法。该算法能够有效处理岗位描述中的稀疏技能特征，并具有极高的预测精度 。模型最终输出的结果不仅包括该岗位在当前市场下的预计起薪和顶薪范围，还会根据行业中位数提供一个具有置信度的参考区间，帮助学生在求职时合理锚定薪资期望。
3.4.2  行业技能图谱模型设计
技能图谱模型通过对全网招聘明细进行深度挖掘，构建出一个能够反映行业技术栈演进的知识网络。该模型的实现核心在于“共现分析”逻辑：系统利用PySpark计算框架对清洗后的岗位描述执行词频统计，分析不同技术标签在同一职位要求中同时出现的频率 。
为了提升图谱的专业度，系统应用了TF-IDF算法对提取到的关键词进行权重修正，自动识别并强化具有高价值的专业技能词汇，同时削弱通用化词汇的影响。在最终生成的图谱中，每一个技能都被定义为网络节点，而技能间的关联强度则体现为连接边的权重。这不仅支撑了前端关于热门技能和技能关联关系的可视化展示，也为后端的智能推荐提供了结构化的背景知识支撑。
3.4.3   智能推荐与路径规划模型设计
推荐推理模型是平台实现个性化服务的核心。它结合了用户的数字化职业画像与实时的市场供需动态，输出闭环式的求职建议 。该模型采用了混合推荐策略，首先利用自然语言处理（NLP）技术将用户的教育背景、已掌握技能及求职偏好转化为高维特征向量，并将其与结构化岗位库中的职位特征进行余弦相似度计算，生成初步的岗位推荐列表。
在生成岗位推荐的同时，模型会进一步调取技能图谱数据执行“技能缺口分析”。通过对比目标岗位的核心要求与用户当前技能树的补集，系统能够精准识别出用户缺失的关键技术点 。最终，模型会利用图谱中的技能阶梯关系，为用户规划出一条从当前现状到目标职位的渐进式学习路径，并形成包含简历优化建议和行动项的综合职业发展计划 。所有计算过程均需在规约要求的响应时间内完成，以保障交互体验的流畅性。
